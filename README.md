## 📌 About the Project

FishingProject started as a simple Python terminal game.

The player can:

* 🎣 Fish in different areas
* 🐟 Catch different types of fish
* ⭐ Gain XP and level up
* 💰 Sell fish
* 🪝 Buy better fishing equipment
* 🗺️ Unlock new fishing areas
* 🎒 Manage an inventory
* 📊 Store fishing data for later analysis

As the project developed, the game became a practical environment for studying data.

Every fishing activity can generate a record containing information such as:

* Player
* Fishing area
* Fish
* Rarity
* Value
* XP
* Equipment

This data is stored in **PostgreSQL** and later analyzed with **Pandas** and visualized with **Matplotlib**.

## 📊 Current Data Analysis

The project can currently answer questions such as:

### Which fish are caught most often?

```text
Sardinha
Atum
Tubarão
```

### How much value was generated by each fish?

The data can be grouped and summed using Pandas.

### How much XP was generated by each rarity?

The project can analyze the relationship between rarity and XP.

### How much value was generated by each equipment?

The current analysis can calculate the total value generated by each fishing rod.

### What is the average value per fishing session?

This is where the `mean()` function became useful.

For example:

```python
df.groupby("equipment")["value"].mean()
```

This is different from calculating the total value.

The total answers:

> How much value did this equipment generate?

The average answers:

> How much value did a fishing session generate on average using this equipment?

This distinction became an important part of my learning process.

# 🧹 Data Cleaning

One interesting part of the project was discovering that data can contain inconsistencies even when the program appears to work correctly.

For example, one old database record contained a different representation of:

```text
Vara Básica
```

which caused Pandas to interpret it as a different category.

The result initially looked like:

```text
Vara Básica       19
Vara B sica        1
```

The data was cleaned in Pandas:

```python
df["equipment"] = df["equipment"].str.replace(
    "\xa0",
    " ",
    regex=False
)

df["equipment"] = df["equipment"].replace(
    "Vara B sica",
    "Vara Básica"
)
```

After cleaning:

```text
Vara Básica          20
Vara Média           20
Vara Profissional    18
```

This was an important lesson:

> **Data analysis is not only about analyzing data. It is also about making sure the data is reliable enough to analyze.**

### Data encoding

The `Vara Básica` problem demonstrated something that is easy to overlook when starting with data:

Different characters or encodings can cause values that look almost identical to humans to become completely different values for a computer.
